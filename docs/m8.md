# M8 Module Specification & Final Verification — Confidence Estimator v0 + Response Synthesis Agent

## 1. Module Overview & Objectives

- **Module ID:** M8
- **Module Name:** Confidence Estimator v0 + Response Synthesis Agent
- **Pipeline Stage:** Output Tier (Services S9 & S10)
- **Primary Objective:** Calculate a multi-dimensional confidence score over claim verification results and logic consistency, and synthesize a fluent, fact-corrected final response with inline citations and transparent error mitigation.

---

## 2. Key Architectural Decisions & Resolved Issues

1. **Service S9: Heuristic Confidence Estimator v0:**
   - Evaluates verification outcomes, evidence retrieval coverage, consensus metrics, and logic consistency.
   - **Formula:**
     $$\text{Confidence} = 0.35 \times \text{verification\_ratio} + 0.35 \times \text{consensus\_score} + 0.15 \times \text{evidence\_coverage} + 0.15 \times \text{logic\_consistency} - \text{stale\_ts\_penalty}$$
   - **Logic Consistency Bounds Clamping:** Clamped `logic_consistency` strictly to $[0.0, 1.0]$ via `max(0.0, min(1.0, logic_score))` to prevent score corruption.

2. **Service S10: Response Synthesis Agent:**
   - **Fuzzy Token & Substring Fallback Matching (`_is_claim_match`):**
     - Upgraded `ResponseSynthesizer._synthesize_fallback` to combine exact substring matching with token overlap similarity ($\ge 0.4$).
     - Resolves sentence replacement failures when atomic claims extracted by M5 are paraphrased or rephrased relative to original sentences.
     - **Unapplied Correction Safeguard:** Automatically appends any unmapped `corrected_text` statements to `final_answer` so no factual corrections are dropped.
   - **Prompt Injection Hardening:**
     - Wrapped all interpolation parameters in `SYNTHESIS_USER_PROMPT` inside explicit XML boundary tags (`<question>`, `<original_answer>`, `<verification_breakdown>`, `<corrected_statements>`, `<unverified_claims>`) to instruct LLMs to treat evidence strictly as data.

## 3. Data Interface & Schema Contracts

### Confidence Metrics Contract (`ConfidenceMetrics`)
- `overall_confidence` (`float`): Aggregated system confidence score $[0.0, 1.0]$.
- `evidence_coverage` (`float`): Fraction of claims supported by retrieved passages $[0.0, 1.0]$.
- `consensus_score` (`float`): Mean verification confidence across claims $[0.0, 1.0]$.
- `verification_ratio` (`float`): Ratio of claims verified as supported $[0.0, 1.0]$.
- `logic_consistency` (`float`): Inter-claim logic validation score $[0.0, 1.0]$.
- `meta` (`dict[str, Any]`): Detailed feature breakdown.

### Synthesized Response Contract (`SynthesizedResponse`)
- `query_id` (`str`): Matches request ID.
- `question` (`str`): Original user query.
- `final_answer` (`str`): Synthesized, fact-corrected final response with inline citations.
- `overall_verdict` (`ClaimVerdictType`): Overall query-level verification verdict.
- `confidence` (`ConfidenceMetrics`): Calculated multi-dimensional confidence breakdown.
- `claim_results` (`list[ClaimVerificationResult]`): Underlying verification results.
- `corrections_made` (`list[str]`): List of corrected claim statements.
- `citations_used` (`list[str]`): Passage IDs or titles cited in the final answer.
